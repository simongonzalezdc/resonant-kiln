# The Kiln — measured overnight economics

Pattern · Numbers (cure, machine time, throughput, hands-on) · The honest gap · How to reproduce

## Part A — the pattern
A local cure-queue: slip, receipt, delivery log.
1. Creative / identity-shaping requests get PARKED, not answered. The refusal
   is deliberate.
2. Delivery refused until cutoff: first 00:00 local time strictly
   after parking.
3. One receipt per delivered slip. Receipt exists = done (idempotent).
4. Slip grammar is injection-safe by construction (block-scalar last).
5. Morning job scheduled 08:30 local (first recorded delivery: 08:31).

`Provenance: the cure-queue README (pattern laws), the job schedule file, and the delivery log.`

## Part B — the numbers (extracted, with provenance)

Read together, these numbers say one thing: the overnight work cost machine
minutes and cents of electricity, and the scarce input was human presence.

Local rig for every number below: a 27B served from a Strix Halo mini-PC
(full recipe in the published stack repo); the small-model run used a laptop
Mac. Every machine-time and throughput number was regenerated by the
canonical extraction scripts and independently audited (five data passes +
a provenance investigation; the audit records live in the project log); the
hands-on totals are pinned at
the recorded database cutoff below and reproduce only against that frozen
point. Dates are local Pacific unless marked UTC.

### Hands-on minutes (agent chat log)
Machine time is minutes; presence is hours — 237 to 770 minutes a day.
Daily session-presence upper bounds, not per-task, not typing time.

| Day | Hands-on, all lanes (min) | Benchmark lane that ran | Machine wall (min) |
|---|---|---|---|
| 08-22 | 237 | first full gate + walk-away + vision + agent (495 trials) | 100 |
| 08-25 | 356 | all 08-25 campaigns (592 trials incl. rejudges) | 160 |
| 08-26 | 435 | 8B-1A1B on Mac (74 trials) | 104 |
| 08-30 | 770 | stack-bench live parity run | 9.2 |
| 08-31 | 510 | measurement-kit build; PR merged; kit published 09-01 | — |

Method, stated exactly: every human turn timestamp in the agent chat log
(8,708 turns at the pinned cutoff, 2026-09-01T01:30:36Z); turns within 5
minutes cluster into one active block; blocks are split at local midnight so
each day keeps its own minutes; a segment's minutes are its first-to-last
span (isolated turns count as 1 minute); the day's total is the sum of
segment minutes. Spans therefore include agent execution time and idle gaps
under 5 minutes — upper bounds, not typing time. The log covers ALL lanes
run that day and does not split per task; the machine-wall column is the
benchmark lane only, so the two sides are not comparable as a ratio.

Provenance: the local agent-session database (human turns only; synthetic
turns filtered; cutoff pinned above); extract file
`kiln-hands-on-extract-20260901.json` (schema v3, method + cutoff embedded).

### The honest gap
Per-TASK hands-on attribution does not exist in the logs — daily totals
only. What is measured: machine wall, overnight hold, outcomes, daily
hands-on presence totals. Electricity is estimated from public rates and
platform draw figures — never metered on our unit.

### How to reproduce
- Throughput: the stack-bench add-on
  (`github.com/simongonzalezdc/resonant-stack-bench`).
- Delegation machine time: the delegation-bench add-on
  (`github.com/simongonzalezdc/resonant-delegation-bench`).
- Every number in this doc: the extraction scripts ship beside it
  (`extract/` — diff against the extract files, never hand-edit; hands-on
  extracts pin the database cutoff recorded inside the file, and reruns at
  the same cutoff reproduce it exactly):

```sh
sh extract/run_all.sh                                            # regenerate + diff all extracts
python3 extract/extract_hands_on.py --cutoff-ms 1788226236000    # pinned hands-on (2026-09-01T01:30:36Z)
```
